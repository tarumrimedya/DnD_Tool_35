Vercel Bulut Veritabanı (Upstash KV) & Özel Kasa Kontrol Ediliyor...

Kendi Vercel hesabınız üzerinden Karakter + Master DB verilerinizi şifreli ve özel olarak eşitleyin.

Vercel Environment Variables içine APP_PIN eklemenize gerek yoktur! Şifrenizi doğrudan yukarıdaki kutuya yazıp "Ayarları Kaydet & Bağlan" dediğinizde şifreniz otomatik olarak veritabanınıza kaydedilir ve uygulamanız kilitlenir.

🔧 İsteğe Bağlı: Doğrudan Upstash REST Bağlantısı (Yerel PC / Offline Test İçin)
❓ Kendi Özel Vercel Veritabanınızı Nasıl Kurarsınız? (1 Dakikalık Rehber)

1. Bu projeyi kendi GitHub hesabınıza aktarın ve Vercel Dashboard ↗ üzerinden ücretsiz Import edin.

2. Vercel proje panelinizde üst menüden Storage ➔ Create Database ➔ Upstash (Serverless Redis / KV) seçip ücretsiz oluşturun ve projenize bağlayın (KV_REST_API_URL ve KV_REST_API_TOKEN otomatik eklenir).

3. Uygulamayı açıp ⚙️ Ayarlar menüsündeki Kişisel Uygulama Şifresi (APP_PIN) kutusuna istediğiniz şifreyi yazıp "Ayarları Kaydet & Bağlan" butonuna tıklayın (veya isterseniz Vercel Environment Variables içine manuel APP_PIN satırı ekleyin).

4. Artık PC, telefon veya tabletten kendi Vercel linkinize girip yalnızca şifrenizi yazarak tüm Karakter ve Master DB verilerinizi otomatik senkronize edebilirsiniz!
