Consolidate / Split Skills House Rule

Switch between Consolidated Mode (7 Groups) and Standard D&D 3.5e RAW (46 Skills)

💡 Rule Explanation & Benefits

Standard D&D 3.5e RAW features 46 individual skills. Inspired by Unearthed Arcana and Pathfinder 1e variant rules, similar skills can be consolidated into 7 groups to streamline skill point allocation and gameplay.

✓ Rank Preservation: A consolidated skill uses the highest rank among its underlying skills. Original ranks are never lost.
✓ Class Skill Inheritance: If any underlying skill is a class skill for your character, the consolidated group is treated as a Class Skill.
